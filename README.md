# دعوتنامه دیجیتال عقدکنان علی و زینب

کارت دعوت دیجیتال، تعاملی و موبایل‌محور مراسم عقدکنان **علی و زینب** — کاملاً مستقل با فونت‌های فارسی لوکال و آماده انتشار رایگان روی **GitHub Pages**.

## ویژگی‌ها

- **فونت‌های فارسی ۱۰۰٪ لوکال (بدون نیاز به Google Fonts):** فونت‌های `Gulzar` (خوشنویسی نستعلیق) و `Vazirmatn` مستقیماً داخل پروژه باندل شده‌اند تا در ایران و بدون فیلترشکن با سرعت آنی بارگذاری شوند.
- **صفحه پاکت تعاملی + انیمیشن سه‌بعدی (GSAP + CSS 3D):** شکستن مهر موم طلایی قلبی، چرخش سه‌بعدی درب پاکت و بیرون آمدن کارت دعوت.
- **افکت قلب‌های معلق با کلیک/لمس:** نمایش ایموجی‌های قلب کیوت و معلق در محل کلیک یا لمس کاربر.
- **پخش‌کننده موسیقی اختصاصی:** آغاز خودکار موسیقی پس از بیرون آمدن کامل کارت دعوت و همگام‌سازی بدون تکرار در کل صفحات.
- **صفحه مجزای جزئیات مراسم:** تاریخ، ساعت، نشانی تالار، شمارش معکوس زنده به وقت تهران (`Asia/Tehran`) و دکمه مسیریابی مستقیم در نشان.

---

## تنظیمات مراسم (`src/config/event.ts`)

1. **تاریخ و سال دقیق مراسم (`EVENT_DATE_ISO`):**
   ```ts
   EVENT_DATE_ISO: '2026-11-26T18:00:00+03:30',
   ```
   در صورت متفاوت بودن سال مراسم، تاریخ میلادی معادل آن را با افست `+03:30` (وقت ایران) تنظیم کنید.

2. **تعویض فایل موسیقی (`MUSIC_SRC`):**
   فایل صوتی فعلی آماده است. برای تغییر آن، فایل `.mp3` جدید را در پوشه `public/assets/music/` قرار دهید و مسیر `MUSIC_SRC` را به `resolvePublicAsset('assets/music/your-song.mp3')` تغییر دهید.

3. **لینک نشان (`NESHAN_DIRECTIONS_URL`):**
   لینک ارسالی شما از قبل ثبت شده و در همان فایل قابل ویرایش است.

## راهنمای انتشار رایگان روی GitHub Pages

پروژه از پیش با `base: './'`، فایل `.nojekyll` و ورک‌فلوی خودکار `.github/workflows/deploy.yml` آماده انتشار است:

1. در GitHub یک مخزن (Repository) جدید از نوع **Public** بسازید (مثلاً `ali-zeynab-wedding`).
2. کدهای پروژه را در شاخه `main` (یا `master`) آپلود / پوش کنید:
   ```bash
   git init
   git add .
   git commit -m "Initial wedding invitation"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/ali-zeynab-wedding.git
   git push -u origin main
   ```
3. وارد تب **Settings** مخزن شوید و از منوی سمت چپ گزینه **Pages** را انتخاب کنید.
4. در بخش **Build and deployment** → گزینه **Source** را روی **GitHub Actions** قرار دهید.
5. وارد تب **Actions** شوید؛ ورک‌فلو به‌صورت خودکار (یا با زدن دکمه **Run workflow**) پروژه را بیلد و منتشر می‌کند.
6. پس از ۱ تا ۲ دقیقه، لینک رایگان و دائمی دعوتنامه شما در بخش **Settings → Pages** نمایش داده می‌شود (مثلاً `https://YOUR_USERNAME.github.io/ali-zeynab-wedding/`).
